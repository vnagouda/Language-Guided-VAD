## Abstract

Weakly Supervised Video Anomaly Detection (WS-VAD) aims to detect anomalous events in untrimmed surveillance videos using only video-level labels during training, while producing frame-level anomaly scores at inference. Current state-of-the-art MIL-based methods rely exclusively on visual features, leading to **context bias** -- confusing visually similar normal and abnormal scenes (e.g., smoke from cooking vs. smoke from an explosion). We propose a novel **Language-Guided Cross-Attention** framework that exploits semantic language descriptions generated by BLIP-2, encoded via CLIP text encoder, as Queries in a cross-attention mechanism with visual features as Keys/Values. This forces the network to selectively attend to visual patterns that correlate with semantic anomaly descriptions. Through 18 systematic architectural iterations addressing the "Lazy Localisation" problem, temporal aliasing, and tri-modal fusion, we achieve a peak single-model Frame-Level AUROC of **83.77%** on the UCF-Crime benchmark -- outperforming the seminal CVPR 2018 baseline by **over 8 percentage points**, with a three-model score-level ensemble reaching **83.80%**. We additionally discover and correct critical evaluation protocol bugs, establish a SOTA-comparable evaluation protocol, conduct an 8-seed reproducibility analysis (0.827 ± 0.004), and validate through negative-result experiments that learned cross-modal alignment is strictly necessary -- raw CLIP semantic similarity and LSTM temporal prediction both degrade to chance level on surveillance footage.

---

## 1. Novel Contributions

1. **Language-Guided Cross-Attention for WS-VAD:** First framework to use text embeddings as semantic Queries in a cross-attention mechanism for weakly supervised video anomaly detection, mathematically forcing visual features to re-weight based on language guidance -- proven empirically superior to feature concatenation (+3.72pp V1 ablation).

2. **Comprehensive Evaluation Protocol Validation:** Discovered and corrected critical evaluation bugs including frame count truncation (74.9% anomaly frame loss) and normal video deflation (6.3x under-estimation), establishing a SOTA-comparable evaluation protocol with 11.4% anomaly ratio.

3. **Temporal Resolution Scaling Breakthrough:** Demonstrated that quadrupling temporal resolution from T=32 to T=128 segments yields significant Frame-AUROC improvement, achieving 82.06% (V12) and enabling further gains in subsequent iterations.

4. **Tri-Modal Fusion with I3D Motion Features:** V13 introduces early fusion of CLIP visual, BLIP-2 language, and I3D motion features via a learnable scalar gate, achieving the best single-model Frame-AUROC of 83.77% -- demonstrating that explicit motion dynamics complement static CLIP appearance features.

5. **Multi-Seed Reproducibility Analysis:** Trained 8 seeds under identical hyperparameters, reporting V12 as 0.827 ± 0.004 with a seed range of 1.4 percentage points -- exceeding typical inter-method differences in WS-VAD literature.

6. **Score-Level Ensemble Analysis:** A 10-model candidate set (8 seeds + 2 architectural variants) achieves 83.80% Frame-AUROC via grid-searched weighted averaging, matching V13 without requiring scarce 2048-dim I3D features.

7. **Negative-Result Validation:** Proved that zero-shot CLIP danger scoring (0.49 AUROC) and LSTM temporal prediction (0.50 AUROC) both degrade to chance, definitively establishing that learned cross-modal alignment is the operative mechanism.

8. **Multi-Objective Loss Architecture:** Designed a multi-component loss function combining Adaptive Instance Selection, Antagonistic Loss, Magnitude Ranking, Snippet Contrastive Learning, Temporal Smoothness Decay, Memory Bank Contrastive Losses, and MIST Self-Training.

## 3. Architecture

### 3.1 Complete Pipeline Overview

```
Phase 1 -- Offline Feature Extraction (run once, ~7 days GPU-time for BLIP-2 on RTX 4060):

  Visual Track:                   Language Track:                 Motion Track (V13+):
  PNG Frames                      PNG Frames (center frame)       Video clips (16-frame windows)
      |                               |                               |
  CLIP ViT-L/14 (768-dim)        BLIP-2 OPT-2.7B (caption gen)  I3D (Kinetics-400 pretrained)
      |                               |                               |
  Visual Features [T, 768]        CLIP Text Encoder (768-dim)    I3D Features [T, 2048]
      |                               |                               |
  --> .pt files                   Text Features [T, 768]         --> .pt files
                                  --> .pt files


Phase 2 -- Online Training (V13 SOTA Architecture):

  Text [B,T,D] -------- Q ---+
                              +-- Cross-Attention --> Guided Features [B,T,D]
  Visual [B,T,D] --- K,V ----+    (Q=Text, K/V=Visual)
       |                                    |
  (V13: V_fused = (1-σ(α))·V_CLIP          |
         + σ(α)·Proj(V_I3D))    +-----------+-----------+
       |                        |           |           |
       |                  Multi-Scale   Hourglass FC  Magnitude
       |                  Temporal Attn (D->64->128->1) Branch
       |                  (T=32,16,8)  Semantic Score  (L2+z-score)
       |                        |           |           |
       |                        +-----+-----+-----+----+
       |                              |           |
       |                    Final Score = sigmoid(Semantic + alpha * Magnitude)
       |                              |
       |                    Multi-Component Loss Function:
       |                    1. AIS Loss (adaptive instance selection)
       |                    2. Antagonistic Loss (top-1 separation)
       |                    3. Magnitude Ranking Loss (L2-norm margin)
       |                    4. Snippet Contrastive Loss (temporal)
       |                    5. Temporal Smoothness (exponential decay)
       |                    6. Feature Contrastive Loss (per-batch)
       |                    7. Memory Bank Contrastive Loss (global)
       |                    8. MIST Self-Training (Phase 2, epoch 50+)


Phase 3 -- Inference and Evaluation:

  Test features --> Forward pass --> T segment scores
  --> Interpolate T --> N frames (actual frame count)
  --> Compare against frame-level ground truth
  --> Frame-AUROC + Video-AUROC + ROC/PR curves
```

### 3.2 Cross-Attention Mechanism (Novel Contribution)

Given visual features V and text features T, both in R^{TxD}:

```
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V

Q = T * W_Q    (Query from text -- the semantic guide)
K = V * W_K    (Key from visual)
V = V * W_V    (Value from visual)
```

**Why Q=Text, K/V=Visual?** The text Query asks: "Given this semantic description, where in the visual sequence should I look?" The visual Key/Value answers: "These are the visual features most semantically relevant to your query." This forces the network to selectively attend to anomaly-relevant visual cues guided by language -- mathematically superior to concatenation because the network must learn explicit cross-modal alignment.

**Implementation:** Multi-Head Attention with 8 heads (d_k = 64 per head), post-norm residual connections, FFN (512 -> 2048 -> 512) with GELU activation.

### 3.3 Multi-Scale Temporal Attention (V4)

Three parallel cross-attention branches operate at T=32, T=16 (pooled 2x), and T=8 (pooled 4x), capturing short, mid, and long-term temporal patterns. Outputs are upsampled back to T=32 and fused via learnable softmax weights:

```
MSCA(T, V) = sum_s w_s * Upsample_T(CrossAttn(Pool_s(T), Pool_s(V)))
where w_s = softmax(alpha)_s are learnable per-scale fusion weights
```

### 3.4 Magnitude Branch (Additive Fusion)

```
s_final = sigmoid(f_sem(guided_t) + alpha * f_mag(z_score(||f_vis||_2)))
```

where alpha is a learnable scalar gate (initialised 0.1). Additive fusion (not multiplicative) prevents gradient saturation -- a critical lesson learned from V2 regression (74.78%).

### 3.5 Tri-Modal Early Fusion (V13)

V13 introduces I3D motion features as a third modality fused with CLIP visual features before cross-attention via a learnable scalar gate:

```
V_fused = (1 - sigmoid(alpha)) * V_CLIP + sigmoid(alpha) * Proj(V_I3D)
```

where Proj: R^2048 -> R^768 is a linear projection with ReLU and dropout. The 2048-dim I3D variant (RGB + Flow stacked, 10-crop) encodes explicit inter-frame motion dynamics that static CLIP features lack. V13 achieves the best single-model Frame-AUROC of 83.77% despite only 37.6% I3D test-set coverage (109 of 290 test videos; remaining 181 use zero-tensor fallback).

**Critical finding:** The V13 result is attributable to the 2048-dim RGB+Flow representation, not the fusion architecture itself. V14--V16 using 1024-dim RGB-only I3D fail to reproduce the gain, confirming that RGB+Flow I3D captures motion information that RGB-only I3D does not.

### 3.6 Key Design Decisions (V12/V13 SOTA)

| Component | Implementation | Rationale |
|-----------|---------------|-----------|
| **Language-Guided Cross-Attention** | Text Queries, Visual Keys/Values | Semantic guidance superior to concatenation |
| **Multi-Scale Temporal Attention** | T=32, 16, 8 parallel branches | Captures hierarchical temporal patterns |
| **Hourglass FC** | D->64->128->1 bottleneck | Parameter efficiency via compression |
| **Magnitude Branch** | L2-norm + z-score + additive gate | Feature intensity independent of semantics |
| **Tri-Modal Fusion (V13)** | Learnable alpha gate blending CLIP + I3D-2048 | Motion dynamics complement static appearance |
| **AIS** | Dynamic K with warm-start (K=8->adaptive) | Replaces rigid Top-K with curriculum learning |
| **Snippet Contrastive (SCL)** | Within-video top-K vs. bottom-K | Fine-grained temporal discrimination |
| **Normal Memory Bank** | 256-entry FIFO + two contrastive losses | Global normal-feature separation |
| **Smoothness Decay** | Exponential decay in Phase 2 | Allows MIST sharp boundaries |
| **MIST Self-Training** | Pseudo-labels from epoch 50+ | Bootstraps bag->instance supervision |
| **T=128 Resolution** | 4x finer segments | Captures split-second boundaries |

## 4. Loss Function (V12 SOTA)

The multi-objective loss combines complementary components:

```
L_total = L_AIS + lambda_ant * L_ant + lambda_mag * L_mag
        + lambda_SCL * L_SCL + lambda_smooth(e) * L_smooth
        + lambda_ctr * L_ctr + lambda_bank * L_bank
        + lambda_self * L_self * 1[e >= 50]
```

| # | Component | Purpose |
|---|-----------|---------|
| 1 | **AIS Loss** | Adaptive instance selection replaces fixed Top-K |
| 2 | **Antagonistic** | Surgically penalize top-1 false alarm, reward top-1 true positive |
| 3 | **Magnitude Ranking** | Inter-bag separation on feature L2-norms |
| 4 | **Snippet Contrastive (SCL)** | Within-video temporal discrimination (V11+) |
| 5 | **Temporal Smoothness** | Score coherence; decays exponentially in Phase 2 |
| 6 | **Feature Contrastive** | Local per-batch normal/anomaly separation |
| 7 | **Memory Bank Contrastive** | Global separation against FIFO normal-feature queue |
| 8 | **MIST Self-Training** | Instance-level pseudo-labels (Phase 2, epoch 50+) |

### Adaptive Instance Selection (AIS)

AIS dynamically adjusts K based on model confidence using temporal roughness and normal bag suppression. Warm-start schedule: K=8 for epochs 1--20, then adaptive with K_min=3 floor.

### Temporal Smoothness Decay

```
lambda_smooth(e) = lambda_0 * 0.95^max(0, e - e_mist)
```

Maintains full temporal coherence during Phase 1 (bag-level MIL) but exponentially decays after MIST activation (epoch 50) to allow sharp boundary emergence.

## 5. Development Journey (V1 to V18)

### Phase 1: Baseline (V1--V2.1)

- **V1:** Proved cross-attention concept (77.14%, beat CVPR 2018 by +1.73pp)
- **V2 (Regression):** Added 4 components simultaneously -> 74.78% (-2.36pp). Root causes identified: (1) multiplicative fusion saturation, (2) K=1 cold-start, (3) 2-layer overfitting, (4) CLIP L2-norm saturation
- **V2.1 (Recovery):** Additive fusion, z-score normalisation, warm-start AIS, K_min=3, gradient clipping -> 79.18% (+4.40pp recovery from V2)
- **Key Lesson:** Combining literature-validated components without diagnostic instrumentation can produce regressions whose root causes are non-obvious.

### Phase 2: Feature Extraction (V3--V3.1)

- **V3 (Florence-2):** Dense spatial grounding with ViT-L/14 (768-dim) and 5-frame averaging -> 76.11%
- **V3.1 (BLIP-2 Anomaly Prompt):** Anomaly-seeking VQA prompt ("Question: What is happening in this image? Answer:") -> 77.95% (+1.84pp)
- **Key Finding:** Task-specific prompting outperforms generic spatial captioning. Florence-2 describes scenes objectively while BLIP-2 with anomaly prompts captures action semantics.

### Phase 3: Architectural Complexity (V4--V7)

- **V4:** Multi-Scale Temporal Attention (T=32,16,8) + Global Normal Memory Bank (256-entry FIFO) + Feature Contrastive Loss -> 81.80% (best T=32 single-model)
- **V5:** Cosine Annealing + Class-Balanced Sampling + K=5 AIS -> 80.42% (MIST trade-off: pseudo-labels truncate long anomaly boundaries)
- **V6:** 16 Dynamic Normal Prototypes -> 77.71% (geometric constraints too rigid, "Siren Effect")
- **V7:** Pyramid Dilated Convolutions (PDC) with dilation {1,2,4} -> 79.31%
- **Key Finding:** At T=32, the SOTA-comparable performance ceiling is approximately 0.818 ± 0.005; additional architectural complexity introduces gradient interference without proportional benefit.

### Phase 4: Protocol Correction and Resolution Scaling (V9--V12)

- **V9--V10:** T=64 + Florence-2 triggered comprehensive forensic audit revealing critical evaluation bugs (see Section 6). V10 introduced Snippet Contrastive Learning (SCL) and Adaptive Smoothness Decay.
- **V11:** V5 + SCL + Smoothness Decay, corrected protocol -> 81.79%.
- **V12 (High-Resolution T=128):** Quadrupled temporal resolution. Fresh CLIP ViT-L/14 visual features at T=128; existing text features linearly interpolated (language context is quasi-stationary). Best seed (s512): 83.31%.

### Phase 5: Tri-Modal Fusion and Ablation Studies (V13--V18)

- **V13 (Tri-Modal Early Fusion):** Learnable scalar alpha blends CLIP and I3D-2048 (RGB+Flow) features before cross-attention -> **83.77%** (best single-model). Only 37.6% I3D test coverage (109/290 videos); remaining received zero-tensor fallback. Full coverage projected to exceed 85%.
- **V14 (Late Fusion, warm-start):** I3D-1024 RGB-only injected via learned attention gate after cross-attention, warm-started from V12 -> 82.25%. Fine-tuning caught between destructive high LR and insufficient low LR.
- **V15 (Late Fusion, from-scratch):** Same V14 architecture trained from scratch -> 81.88%. Underperforms V12 alone.
- **V16 (Early Fusion, I3D-1024):** Full 1,610 training set with 1024-dim I3D -> 80.84%. Confirms 1024-dim RGB-only I3D actively corrupts CLIP feature space.
- **V17 (No-MIST Ablation):** V12 architecture with MIST disabled -> 82.85% (peak at epoch 54). MIST contributes essentially nothing to peak Frame-AUROC; best checkpoint is always saved at Phase-1 peak regardless.
- **V18 (Focal-Loss Fine-Tune):** Fine-tuned V12_s777 with Focal MIL loss (γ=2) -> 82.64%. Degrades monotonically; focal weighting zeros gradient from already-confident segments without sufficiently improving hard boundary segments.
- **Key Finding:** The V13 result is attributable to the 2048-dim RGB+Flow I3D representation, not the fusion architecture. MIST is useful only with continuous evaluation and early stopping; focal loss is better suited to training from scratch than fine-tuning.

### Negative Results (SENTINEL Extensions)

- **Extension 1 -- Zero-Shot CLIP Danger Score:** Cosine similarity between BLIP-2 caption features and 20 danger-phrase embeddings. Standalone AUROC: **0.49** (chance level). CLIP domain gap on CCTV confirmed.
- **Extension 2 -- LSTM Temporal Prediction Error:** Bi-LSTM Autoencoder (768->256->768) on 789 normal videos. Standalone AUROC: **0.50** (random). T=32 too coarse for motion modelling.
- **Conclusion:** Raw semantic spaces of CLIP and sequential temporal dynamics cannot replace explicit cross-modal training. Learned alignment is strictly necessary.

## 6. Evaluation Protocol Validation

### 6.1 Seven Critical Bugs Discovered

During V9--V10 development, a comprehensive forensic audit revealed 7 systematic bugs corrupting all prior Frame-AUROC measurements.

| Bug # | Description | Impact | Fix |
|:-----:|-------------|--------|-----|
| 1 | **Frame count truncation** | 74.9% anomaly frames mislabeled as normal | Use max(annotation_max+1, extracted) as N |
| 2 | **Post-hoc Gaussian smoothing** | sigma=2.0 smears sharp temporal boundaries | Controlled application post-inference only |
| 3 | **YAML-to-Python key mismatches** | 5 loss weights silently defaulted | Fallback alias mapping in from_config() |
| 4 | **Dead magnitude loss** | L_mag = 0.0000 for 1000 epochs | Recalibrate hinge margin delta=5.0 |
| 5 | **Smoothness antagonising MIST** | Sharp pseudo-label boundaries penalised | Exponential decay lambda_smooth(e) |
| 6 | **Prototype count config mismatch** | Key name mismatch (correct default by coincidence) | Support both naming conventions |
| 7 | **Normal video frame count deflation** | 6.3x under-estimation of normal frames | Apply median subsampling ratio (6.29) |

### 6.2 Bug #1: Frame Count Truncation (CRITICAL)

The evaluation module estimated total frames as N = T x 16 = 32 x 16 = 1024. However, UCF-Crime videos can have up to 10,335 original frames. Any annotation with start_frame > 1024 was silently discarded: **63,080 of 84,189 anomaly frames (74.9%)** were mislabeled as normal across 79/140 anomaly videos.

### 6.3 Bug #7: Normal Video Deflation (CRITICAL)

Normal videos have no temporal annotations (all entries [-1,-1,-1,-1]), so the evaluator used extracted frame counts (post-subsampling) rather than original video lengths. The median subsampling ratio (from 140 anomalous videos) was 6.29x, deflating the normal frame pool by ~400,000 frames and inflating the anomaly ratio from 11.4% to 24.6%.

### 6.4 Protocol Correction Impact

| Metric | Before Fix | After Fix | SOTA Standard |
|--------|:----------:|:---------:|:-------------:|

## 7. Critical Findings

### 7.1 Temporal Resolution and Tri-Modal Fusion

```
T=32  (V1):   77.14% -- Each segment spans 3--10 seconds
T=128 (V12):  82.06% -- Each segment spans 0.75--2.5 seconds
+I3D  (V13):  83.77% -- Tri-modal with motion features (best single-model)
Ensemble:     83.80% -- Seed + architectural diversity (best overall)
```

Beyond T=128, diminishing returns expected: the remaining gap to SOTA (84--88%) is attributed to incomplete I3D coverage (37.6%) and the absence of dense RGB+Flow features at full scale.

### 7.2 Language Modality Validation

| Approach | Frame-AUROC | Finding |
|----------|:-----------:|---------|
| BLIP-2 anomaly VQA prompt | 77.95% | Task-specific prompts critical |
| Florence-2 spatial captions | 76.11% | Generic descriptions underperform (-1.84pp) |
| CLIP zero-shot danger score | 0.49 | Raw embeddings fail entirely (domain gap) |
| LSTM temporal prediction | 0.50 | Sequential dynamics fail at T=32 granularity |

### 7.3 MIST Self-Training Pathology

MIST consistently improved video-level AUROC while degrading frame-level AUROC by 1--2pp across V4, V12, V14, V15, and V12_s777. The mechanism: pseudo-labels derived from the model's own argmax become increasingly confident, reinforcing minor mis-localisations rather than correcting them. V17 (no-MIST ablation) confirms: peak Frame-AUROC of 82.85% vs V12_s777's 82.94% -- MIST contributes essentially nothing to peak performance. Practical implication: MIST should be disabled unless continuous frame-level evaluation and aggressive early stopping are available.

### 7.4 V13--V16: Isolating the I3D Variable

| Version | I3D Variant | Coverage | Frame-AUROC | Finding |
|---------|------------|:--------:|:-----------:|---------|
| V13 | 2048-dim RGB+Flow | 37.6% | 83.77% | Best single-model |
| V14 | 1024-dim RGB-only | 1,001 vids | 82.25% | Marginal over V12 |
| V15 | 1024-dim RGB-only | 1,001 vids | 81.88% | Below V12 |
| V16 | 1024-dim RGB-only | 1,610 vids | 80.84% | Corrupts CLIP features |

The 2048-dim RGB+Flow representation encodes motion information that 1024-dim RGB-only I3D simply does not. A complete tri-modal SOTA requires RGB+Flow I3D at full test-set coverage.

### 7.5 Architectural Saturation After V4

At T=32, additional complexity degraded Frame-AUROC: V4 (81.80%) -> V5 (80.42%) -> V6 (77.71%) -> V7 (79.31%). The HPO-tuned V4 loss landscape was near-optimal; breaking the ceiling required richer features (V13) or higher temporal resolution (V12), not more parameters.

### 7.6 Focal Loss Failure (V18)

Fine-tuning a converged model with focal loss (γ=2) degrades monotonically from 82.93% to 82.64%. Focal weighting effectively zeros gradient from already-confident segments, destabilising learned representations without sufficiently improving hard boundary segments. Focal loss is better suited to training from scratch.

## 13. Limitations and Theoretical Ceiling

1. **Static Spatial Features:** CLIP ViT encodes individual frames without inter-frame motion context. V13 demonstrates that adding I3D motion features yields +1.71pp, but full-coverage RGB+Flow I3D features remain unavailable -- V13's result relies on only 37.6% test-set I3D coverage.

2. **Domain Gap:** CLIP was pre-trained on internet images + alt-text, not grainy CCTV footage. Surveillance-specific fine-tuning could improve alignment quality. The zero-shot CLIP danger scoring experiment (0.49 AUROC) quantifies this gap.

3. **MIL Supervision Ceiling:** Without explicit frame-level annotations during training, the model can only bootstrap from bag-level labels. MIST self-training is empirically harmful to peak Frame-AUROC (V17 ablation), suggesting the MIL ceiling is real.

4. **Captioner Limitations:** BLIP-2 describes content objectively -- a robbery may generate "a person standing near a car" rather than recognising the anomaly. Anomaly-specific prompting (+1.84pp) partially addresses this.

5. **HPO Test-Set Bias:** HPO uses the test set for hyperparameter selection, slightly biasing reported single-best AUROC upward. The multi-seed analysis quantifies this at approximately ±0.4pp.

6. **Training Set Size:** Our 1,610 training videos is smaller than the ~1,900 commonly reported because the pre-extracted PNG distribution omitted some videos.

## 14. Future Work

### Dense RGB+Flow I3D Features (Priority #1)
Based on V13's 83.77% with only 37.6% I3D coverage, full-coverage RGB+Flow I3D features may exceed 85%. This is the single highest-impact direction identified.

### Modern Video Foundation Models
InternVideo2, VideoMAE-v2, and similar models produce 1024--2048-dim features with strong temporal encoding -- a natural drop-in replacement for CLIP frame embeddings that may close the gap to MGFN/Sun et al.

### Stochastic Weight Averaging (SWA)
SWA over the flat region of each cosine cycle has shown consistent 0.5--1pp gains in classification tasks and is a low-cost addition to the pipeline.

### Enhanced Language Guidance
- Anomaly-aware caption prompting (e.g., "describe any unusual or dangerous activity in this scene")
- Category-specific text prototypes
- LLM-generated anomaly descriptions (GPT-4 guided BLIP-2 prompting)
- Caption quality filtering based on CLIP alignment scores

### Deeper Cross-Attention
Pre-LayerNorm and residual scaling combined with curriculum-style depth training may permit the second attention layer that V2 was unable to use stably on a 1,610-video dataset.

### Cross-Dataset Evaluation
Evaluation on XD-Violence and per-category error analysis on the thirteen UCF-Crime anomaly classes are essential for establishing generalisation properties of language-guided WS-VAD.
